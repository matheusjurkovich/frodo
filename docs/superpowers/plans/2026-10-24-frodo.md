# Frodo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extensão nativa do GNOME Shell 50 que mostra uma "dynamic island" no topo (hora, bateria, RAM, uso do Claude Code, notificações, bandeja, controles rápidos), leve em RAM e com visual Lydia.

**Architecture:** Uma extensão GJS (ESM) sem processo próprio. Lógica pura (parsing de `/proc/meminfo` e da API de uso do Claude) fica em `lib/` sem imports do shell e é testada com `gjs -m`. Um hub `Data` concentra as fontes (RAM, bateria, Claude) e emite eventos. A `Island` (pílula + painel) só consome `Data` e os adaptadores (`controls`, `notifications`, `tray`, `topbar`).

**Tech Stack:** GJS 1.88, GNOME Shell 50 (Wayland), St/Clutter, Gio/GLib, Soup 3, NM, GnomeBluetooth, GSettings, Adwaita (prefs).

**Spec:** `docs/superpowers/specs/2026-10-24-frodo-design.md`, mockups em `docs/mockups/`.

## Global Constraints

- `metadata.json`: `uuid` = `frodo@matheusjurkovich`, `shell-version` = `["50"]`, `settings-schema` = `org.gnome.shell.extensions.frodo`.
- Nenhum processo extra, nenhuma dependência npm em runtime, nenhum WebView.
- **Sem comentários no código** (`//`, `/* */`, JSDoc, `<!-- -->`), inclusive testes e XML. Exceção única: diretivas exigidas por ferramenta.
- Textos de UI em português do Brasil, hardcoded (sem gettext).
- Visual sempre escuro: pílula `#000` com raio total, painel `#000` com raio 22px, tiles `#1a1a1a`, tile ligado `#2b5fd9`, texto secundário `#9aa0a6`, barra Claude `#d97757`, barra RAM `#7aa2f7`, barra bateria `#7bd88f`.
- Polling: RAM a cada 5s **só enquanto visível**. Claude a cada `claude-poll-minutes` (padrão 5, mínimo 2), mais refresh ao abrir o painel se o dado tiver mais de 60s. Bateria só por sinal D-Bus.
- Uso do Claude somente leitura: nunca renovar token, nunca escrever em `.credentials.json`, nunca logar o token.
- Todo `connect`, timer, patch e reparent feito em `enable()` é desfeito em `disable()`.
- Para checar nomes internos do shell: `gresource extract /usr/bin/gnome-shell /org/gnome/shell/<caminho>.js` (alguns estão em `/usr/lib/gnome-shell/libshell-18.so`).

## Review Focus

1. **Bloquear e desbloquear a tela** chama `disable()` e `enable()`. A barra superior, o `dateMenu`, os ícones da bandeja e o `messageTray` precisam voltar exatamente como estavam, sem timers órfãos. Teste no Task 12, passo 2.
2. **Sem rede, API 5xx, JSON quebrado ou 401:** barras do Claude mostram "—" com tooltip, sem exceção no log. Testes `parseUsage` com lixo e `errorForStatus` no Task 2.
3. **Sem `~/.claude/.credentials.json`** (Claude Code nunca logado): estado `no-credentials` com tooltip "Faça login no Claude Code". Teste `readToken` no Task 2.
4. **Ícone da bandeja some enquanto o painel está aberto** (app fechou): devolver os ícones não pode quebrar com ator destruído. Verificação manual no Task 10, passo 3.
5. **Notebook sem bateria ou desktop:** item de bateria some da pílula e do painel, sem buraco no layout. Verificação manual no Task 4, passo 4.

### Task 2: Parsers puros (RAM e Claude) com testes

**Files:**
- Create: `lib/meminfo.js`, `lib/claude.js`, `tests/run.js`

**Interfaces:**
- Produces:
  - `parseMeminfo(text: string) -> {totalKb: number, usedKb: number} | null`, com `usedKb = MemTotal - MemAvailable`
  - `formatGb(kb: number) -> string`, com uma casa decimal e sufixo `G` (`6501171` → `"6.2G"`)
  - `parseUsage(json: any) -> {session: Win|null, weekly: Win|null}`, onde `Win = {percent: number, resetsAt: string|null}`
  - `readToken(text: string|null, nowMs: number) -> {token: string|null, error: null|'no-credentials'|'expired'}`
  - `errorForStatus(status: number) -> null|'expired'|'http'`
  - `formatReset(iso: string|null, nowMs: number) -> string`
  - `credentialsPath() -> string`, que usa `$CLAUDE_CONFIG_DIR/.credentials.json` se a variável existir, senão `~/.claude/.credentials.json`
- `lib/*.js` só importa `gi://GLib`, `gi://Gio` e `gi://Soup`, nunca `resource:///org/gnome/shell/...`.

- [ ] **Step 1: Escrever `tests/run.js`** com um `assertEq(a, b, name)` mínimo que acumula falhas e termina com `imports.system.exit(1)` se houver alguma (em ESM: `import System from 'system'`). Casos:

```js
assertEq(parseMeminfo('MemTotal:       14680064 kB\nMemFree: 1 kB\nMemAvailable:    8178893 kB\n'), {totalKb: 14680064, usedKb: 6501171}, 'meminfo');
assertEq(parseMeminfo('lixo'), null, 'meminfo lixo');
assertEq(formatGb(6501171), '6.2G', 'formatGb');

assertEq(parseUsage({limits: [
  {kind: 'session', group: 'session', percent: 62, resets_at: '2026-10-24T20:00:00Z'},
  {kind: 'weekly_all', group: 'weekly', percent: 31, resets_at: '2026-10-29T12:00:00Z'},
  {kind: 'weekly_scoped', group: 'weekly', percent: 80, scope: {model: {display_name: 'Opus'}}},
]}), {session: {percent: 62, resetsAt: '2026-10-24T20:00:00Z'}, weekly: {percent: 31, resetsAt: '2026-10-29T12:00:00Z'}}, 'usage limits');
assertEq(parseUsage({five_hour: {utilization: 10, resets_at: 'a'}, seven_day: {utilization: 20, resets_at: 'b'}}),
  {session: {percent: 10, resetsAt: 'a'}, weekly: {percent: 20, resetsAt: 'b'}}, 'usage legado');
assertEq(parseUsage(null), {session: null, weekly: null}, 'usage null');
assertEq(parseUsage({limits: [{kind: 'session', percent: 'x'}]}), {session: null, weekly: null}, 'usage percent inválido');

assertEq(readToken(null, 0), {token: null, error: 'no-credentials'}, 'token sem arquivo');
assertEq(readToken('{quebrado', 0), {token: null, error: 'no-credentials'}, 'token json quebrado');
assertEq(readToken('{"claudeAiOauth":{"accessToken":"t","expiresAt":1000}}', 2000), {token: null, error: 'expired'}, 'token expirado');
assertEq(readToken('{"claudeAiOauth":{"accessToken":"t","expiresAt":3000}}', 2000), {token: 't', error: null}, 'token ok');
assertEq(readToken('{"claudeAiOauth":{"accessToken":"t"}}', 2000), {token: 't', error: null}, 'token sem expiresAt');

assertEq(errorForStatus(200), null, 'status 200');
assertEq(errorForStatus(401), 'expired', 'status 401');
assertEq(errorForStatus(503), 'http', 'status 503');

const now = Date.UTC(2026, 9, 24, 12, 0);
assertEq(formatReset(new Date(now + 130 * 60e3).toISOString(), now), 'em 2h 10m', 'reset horas');
assertEq(formatReset(new Date(now + 45 * 60e3).toISOString(), now), 'em 45m', 'reset minutos');
const far = new Date(now + 3 * 86400e3);
assertEq(formatReset(far.toISOString(), now),
  `${['dom','seg','ter','qua','qui','sex','sáb'][far.getDay()]} ${String(far.getHours()).padStart(2,'0')}:${String(far.getMinutes()).padStart(2,'0')}`, 'reset dias');
assertEq(formatReset(null, now), '', 'reset nulo');
```

Regra de `formatReset`: menos de 1h → `em Nm`. Menos de 24h → `em Hh Mm`. Senão → dia da semana abreviado + `HH:MM` local.
Regra de `parseUsage`, usando `limits[]` se for array não vazio:
- session = entrada com `kind === 'session' || group === 'session'`
- weekly = `kind === 'weekly_all'`, ou `group === 'weekly'` sem `scope`
- entradas com `percent` não numérico são ignoradas

Sem `limits[]`, usar `five_hour` e `seven_day` (`utilization`, `resets_at`).
